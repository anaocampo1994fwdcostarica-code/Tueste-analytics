# Matriz RACI propuesta

## Estado

Matriz académica propuesta; no representa roles configurados ni permisos
implementados. R = ejecuta/prepara, A = aprueba y responde, C = consultado,
I = informado. El orquestador coordina, pero no reemplaza al responsable humano.

Roles:

- **Usuario/gerencia (UG)**
- **Responsable de marketing (MK)**
- **Responsable de ventas (VT)**
- **Responsable editorial/revisor (RV)**
- **Operaciones/servicio (OP)**
- **Orquestador propuesto (ORQ)**
- **Agente especializado aplicable (AGE)**
- **Analítica (ANA)**

## Reglas RACI

- Cada actividad tiene una sola autoridad final `A` cuando se implemente.
- Ningún agente especializado recibe `A` para gasto, publicación, contacto,
  venta, cobro, suscripción o modificación de datos.
- El orquestador es `C` o coordinador, no propietario de la decisión comercial.
- Una tarea puede cambiar de agente únicamente mediante una nueva asignación del
  orquestador.
- Los roles definitivos y nombres de personas deben ser aportados por Tueste o
  por el estudiante; los anteriores son roles genéricos.
